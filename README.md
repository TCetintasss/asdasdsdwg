# Pixel-Perfect Tech Pack Filler

This small browser app fills a fixed master tech-pack template without redesigning it.

## Master template rules

- The uploaded master template is drawn as the locked background.
- Boxes, borders, titles, spacing, and section sizes are never redrawn or modified.
- Uploaded flat sketches, logo, and swatch images are clipped and scaled only inside their designated boxes.
- Size chart and construction notes are clipped to their existing template areas.

## Usage

1. Open `index.html` in a browser.
2. Upload the master template image.
3. Upload any generated flat sketches or assets into the matching fields.
4. Enter size-chart rows with `code | measurement | size`.
5. Enter construction notes one per line.
6. Download the completed PNG.
